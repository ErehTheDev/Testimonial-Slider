# 💬 Testimonials Slider

An interactive testimonials slider built with **HTML**, **CSS**, and **JavaScript**.  
It allows you to display user feedback or client testimonials in a clean, animated, and user-friendly carousel format.

## 📚 About This Project

This project was created by following a **detailed tutorial** that guided me step-by-step through the development of a testimonial carousel.  
At times it was quite challenging, especially because it involved **JavaScript features** I hadn’t practiced much before — like dynamically changing DOM elements and managing slide indexes.

However, it turned out to be a **great opportunity to improve my understanding** of JavaScript logic, and I also had the chance to **enhance the visual presentation** using advanced CSS styling techniques.

It was especially useful for understanding how to structure content dynamically in **HTML**, which can be surprisingly complex when paired with logic and interactivity.

## 🛠️ Technologies Used

- **HTML5** – To structure the testimonial content and slider layout
- **CSS3** – For layout, styling, transitions, and responsiveness
- **JavaScript** – To handle slider navigation, interactivity, and logic

## 💡 What I Learned

- Dynamic content updates using the DOM
- How to create a smooth sliding experience
- Logic for cycling through multiple testimonials
- Clean UI design and responsiveness using CSS Flexbox
